# Icon sources

LinkedIn, Google Scholar, GitHub, ORCID and ResearchGate PNG icons were copied from the owner's existing website icon folder.

X and Bluesky SVG icons were retrieved from the Simple Icons project:

- https://github.com/simple-icons/simple-icons/blob/develop/icons/x.svg
- https://github.com/simple-icons/simple-icons/blob/develop/icons/bluesky.svg

Simple Icons distributes its icons under CC0; brand names and logos remain subject to their respective trademark rights. Files are stored locally so the site does not require third-party icon requests.

LinkedIn and GitHub now use transparent SVG geometry from Bootstrap Icons (MIT): https://github.com/twbs/icons . ORCID uses Simple Icons: https://github.com/simple-icons/simple-icons/blob/develop/icons/orcid.svg . Brand colours are applied in each SVG. Original PNGs are retained unused.
